Quire 0.4.0 improves writing and navigating multi-file LaTeX projects.

## Highlights

- Standard and Vim keymaps, relative line numbers, multiple cursors, folding, and project-aware citation and reference completion.
- Fast project-wide search, a document outline, and Quick Open for files, projects, and commands.
- Pin, reorder, or reopen tabs. Drag folders in to open projects and drop files into a project to import them.
- Bidirectional SyncTeX, selectable PDF text, page jumps, and side-by-side or stacked views.
- Clickable build diagnostics, searchable settings, customizable shortcuts, and template previews.
- Safer concurrent saves, recovery options for local edit conflicts, and automatic retries for temporary Overleaf connection failures.

## Packages

| File | Platform |
| --- | --- |
| `Quire-0.4.0-mac-universal.dmg` | macOS, Apple Silicon and Intel |
| `Quire-0.4.0-linux-x64.tar.gz` | Linux x86-64 |
| `Quire-0.4.0-linux-arm64.tar.gz` | Linux ARM64 |
| `SHA256SUMS.txt` | SHA-256 checksums for the three packages |

The macOS DMG is an ad hoc signed, unnotarized build. Both Linux archives opened Quire and compiled the sample project on native Ubuntu 24.04 runners. Ubuntu 24.04 needs the Quire AppArmor profile to start with Chromium sandboxing enabled. [Linux installation guide](../install-linux.md) · [Linux test results](https://github.com/WiaderekB/Quire/actions/runs/45998171392)

Install `latexmk` and the TeX packages used by your documents to compile locally. Overleaf sync requires Git, and the optional MCP server requires Node.js 24.
