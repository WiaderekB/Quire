Quire 0.3.0 brings a redesigned writing workspace and downloadable packages for macOS and Linux.

## Highlights

- A graphite interface, a new app icon, and System, Light, and Dark appearances.
- File tabs that retain undo history, a resizable source and PDF split, Quick Open, and Focus mode.
- Article, lab report, and coursework templates with fields for title, author, and course. The source toolbar can insert a section, equation, or table.
- Optional automatic compilation after edits. A failed build keeps the last successful PDF visible.
- A local MCP server with read access to one project by default and opt-in, revision-checked source edits.
- Offline autosave and two-way Git sync with supported Overleaf projects.

## Packages

| File | Platform |
| --- | --- |
| `Quire-0.3.0-mac-universal.dmg` | macOS, Apple Silicon and Intel |
| `Quire-0.3.0-linux-x64.tar.gz` | Linux x86-64 |
| `Quire-0.3.0-linux-arm64.tar.gz` | Linux ARM64 |
| `SHA256SUMS.txt` | Checksums for the three downloads |

The macOS DMG is ad hoc signed and unnotarized. The packaged app was exercised on Apple Silicon. Both Linux archives were built and inspected. Native Linux runtime testing is pending.

Install `latexmk` and the TeX packages your projects use for local PDF builds. After extracting a Linux archive, run the `quire` executable inside.
